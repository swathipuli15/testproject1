# Console-Based Naukri Job Portal

##  Project Overview

The **Console-Based Naukri Job Portal** is a Java console application that simulates a basic HR communication and candidate screening process.
The application collects candidate details such as name, educational qualification, work experience, technical skills, and expected salary. Based on predefined job requirements, the application checks whether the candidate's profile matches the requirements and displays the appropriate HR response.
This project was developed to practice **Java conditional statements, user input, strings, and logical operators**.

##  Objectives
- Create a simple console-based job screening application.
- Collect candidate information through the console.
- Validate educational qualification.
- Check candidate experience.
- Validate technical skills.
- Check expected salary against the company's budget.
- Display the candidate's screening result.

## ✨ Features
The application performs the following steps:
1. Takes the candidate's name.
2. Collects educational qualification.
3. Checks whether the qualification meets the requirement.
4. Collects work experience.
5. Checks whether experience is within the required range.
6. Collects technical skills.
7. Checks for required skills such as Java or SQL.
8. Collects expected salary.
9. Compares the expected salary with the company's budget.
10. Displays the final screening result.

## 📋 Job Requirements
The current application uses the following screening criteria:
| Requirement | Criteria |
|---|---|
| Educational Qualification | 12 or above |
| Experience | 1–5 years |
| Technical Skills | Java or SQL |
| Expected Salary | ₹2,00,000–₹4,00,000 |
